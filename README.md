# Kvadratnyi Metr Launch

The brief is approved. Stop planning and implement the actual
website now.
Create a complete, responsive landing page for the construction
materials store "Квадратний метр" in Bobrynets, Ukraine.
IMPORTANT: The website must be fully optimized for mobile phones,
tablets, laptops, and desktop computers. Mobile usability is
a top priority.
1. HEADER
- Store logo and navigation.
- Working Ukrainian/English language switcher (UA | EN).
- Responsive navigation menu.
- On mobile devices, use a compact hamburger menu.
- Ensure all navigation items are easy to tap.
2. HERO SECTION
- Large photographic background.
- Frosted-glass panel with the main headline.
- Orange primary CTA and glass-style secondary CTA.
- Adapt typography, spacing, and image positioning to every screen.
- On small screens, stack content vertically and prevent overflow.
3. PRODUCT CATEGORIES
- Responsive grid of construction materials and tools.
- 3 or 4 columns on large screens, 2 on tablets, and 1 or 2 on phones.
- Attractive images and translucent glass cards.
- Cards must remain readable and easy to interact with on touchscreens.
4. ABOUT AND ADVANTAGES
- Modern layout with photographs and glassmorphism cards.
- Reorganize content vertically on smaller screens.
5. CUSTOMER REVIEWS
- Responsive review cards.
- Do not invent customer testimonials or ratings.
6. PRICE INQUIRY
- Clear CTA buttons for product and price inquiries.
- Buttons must be easy to tap on mobile devices.
7. CONTACTS
- Store address, Instagram, Facebook, and contact form.
- Use a responsive layout.
- Form fields must be comfortable to use on smartphones.
- Do not invent missing contact details.
8. VOICE AI ASSISTANT
- Floating microphone button in the bottom-right corner.
- Clicking it opens a complete glassmorphism chat panel.
- Adapt the assistant window to desktop, tablet, and mobile.
- On mobile, use a compact panel or a near-full-screen interface.
- Ensure the microphone, text input, and send button are easy to use.
- Prevent the assistant from covering important navigation or form controls.
- Prepare the interface for integration with a real ElevenLabs agent.
- Do not simulate real voice functionality before integration.
DESIGN:
- Glassmorphism style.
- Primary orange: #F97316.
- Dark charcoal: #292929.
- Light gray: #F3F4F6.
- Semi-transparent containers.
- Backdrop blur, subtle borders, and soft shadows.
- Smooth, restrained animations.
- Modern typography and excellent readability.
LANGUAGES:
- Ukrainian is the default language.
- Include a working UA | EN language switcher.
- Translate all interface text, buttons, forms, and notifications.
- Save the selected language in localStorage.
- Do not reload the page when switching languages.
RESPONSIVE REQUIREMENTS:
- Use a mobile-first approach.
- Support screen widths from 320px upwards.
- Test layouts at 320px, 375px, 430px, 768px, 1024px,
  1280px, and 1440px.
- No horizontal scrolling.
- No overlapping elements.
- Images must scale correctly without distortion.
- Use responsive typography and spacing.
- Respect touch interactions and keyboard accessibility.
- Respect reduced-motion preferences.
TECHNICAL REQUIREMENTS:
- Use semantic HTML and accessible controls.
- Add basic SEO metadata.
- Optimize images and loading performance.
- Ensure navigation and CTA buttons work.
- Do not claim that forms or voice functionality work unless
  they are actually connected and tested.
Build the complete website now, not just a plan.
After implementation, explain which integrations are still needed
for the contact form and the ElevenLabs voice assistant.
